# LAB03 : Regression & Classification

## Machine Learning Laboratory 3

This project demonstrates the application of Supervised Machine Learning using Regression and Classification algorithms with Python and Scikit-learn.

---

## Dataset

**Dataset:** Age Gender Dataset (UTKFace)

Source: https://www.kaggle.com/datasets/jangedoo/utkface-new

---

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## Machine Learning Models

### Regression

- Simple Linear Regression
- Multiple Linear Regression

### Classification

- Logistic Regression

### Feature Reduction

- Principal Component Analysis (PCA)
